# Исторический stash правил gateway

Этот неактивный patch сохраняет незащищённую часть локального stash
`f9e6aae92a4ff6aa100da2b6432619d239252072` от базы
`bd2c14a6209e7f8cc2a6f866e24d1c30d6f5b2ce`. В нём записаны 24 исторических
адреса символьных ссылок правил Codex/Gemini и старое изменение `AGENTS.md`.
Patch не активирует эти правила: перед применением проверьте их актуальность
относительно текущих общих правил.

`CLAUDE.md`, все пути `.claude` и 11 неотслеживаемых файлов Claude исключены.
Их источники — исходный полный stash и его отдельная приватная резервная копия;
этот patch не является полной копией stash. Родитель индекса совпадает с базой
для всех 25 включённых путей.

Для просмотра сохранённых версий скопируйте `nonprotected.patch` в приватное
место. В отдельном временном checkout точной базы выполните
`git apply --index --unidiff-zero /path/to/nonprotected.patch`. Не применяйте
его в активной рабочей копии без проверки. Patch сохраняет режимы символьных
ссылок и идентификаторы Git-объектов; база доступна в истории `main`.
